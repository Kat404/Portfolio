Mi Vida

Actualmente soy un estudiante en Ingeniería en Sistemas Computacionales, me gustan mucho los Sistemas Operativos, en especial los tipo UNIX, me quiero enfocar en el desarrollo FrontEnd, diseño web y todo lo que tenga que ver con la UI/UX de Interfaces Gráficas para usuarios modernos y exigentes.

Aficiones y Enfoques

  • Sistemas Operativos: Linux (Arch Linux), FreeBSD & próximamente OpenBSD.
  • Desarrollo Web (Aprendizaje Temprano): HTML y CSS, con determinación para dominar frameworks para FrontEnd como Astro con React y frameworks de CSS como Bootstrap o TailwindCSS.
  • Mejoramiento de la seguridad & privacidad de sistemas y navegadores: AdBlockers, Firewalls, Sandboxing, etc.

Mis Gustos

Dentro de mis gustos personales están:

  • El helado de vainilla y café
  • Los gatos obviamente
  • Programar y aprender cada día más y más
  • Hacer ejercicio de manera casual pero constante

Mis Proyectos

  • Configuración Out-of-the-Box para mejorar la seguridad nativa de Linux mediante systemd
  • ZSH-Terminal: Guía básica para el uso y personalización de la shell Zsh
  • FISH-Terminal: Guía básica para el uso y personalización de la shell Fish
  • Dotfiles: Configuración personal para sistemas operativos Linux y demás configuraciones para mucho software que utilizo para desarrollar y vivir Linux de manera Awesome
  • Hotel Quinta Dalam: Sitio web Hotelero personalizado para cliente en Michoacán, México. Desarrollado en pares usando Astro, React & JS nativo. Primer proyecto real en un ámbito formal.

Tecnologías de Interés

Fundamentalmente son las básicas dentro del desarrollo web:

  • HTML
  • CSS
  • JavaScript

Fuera de los lenguajes de marcado, estilo y programación "básicos", me encanta estar aprendiendo acerca de:

  • Framework Principal: Astro, me encanta el hecho de poder modular, crear y usar componentes, layouts y diferentes recursos para el proyecto en el que esté trabajando o en futuros proyectos.
  • Librería Popular: React, me gusta la idea de poner implementar y complementar las diferentes capacidades y ventajas de Astro con un toque moderno, portable y con un transfondo sumamente comercial y con mucha documentación aunque su complejidad sea relativamente alta al principio.
"Todo aprendizaje lleva tiempo, sudor y esfuerzo. Es un largo camino pero no imposible de cursar"
