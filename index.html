Qué hago

Construyo sitios web que tienen que cobrar: sistemas de reserva, cotizadores y plataformas internas que se usan a diario. Trabajo con Astro, Svelte y Cloudflare Workers, y entrego el código, no solo la pantalla.

  • Sitios que venden. Del formulario de cotización al pago. Uno de los míos está en producción generando ingresos hoy.
  • Plataformas internas. Roles, sesiones, persistencia y despliegue en la nube de borde. La que uso para dar un curso del IEEE Computer Society corre sobre D1 y Durable Objects.
  • Ingeniería de sistemas. Linux, redes, hardened y automatización. Rust y TypeScript según lo que pida el problema.

Stack

Esta es la herramienta con la que entrego, con la versión con la que está en producción hoy. No es una lista de deseos: cada línea corresponde a algo que ya corre.

  • Sitios: Astro 7 con Svelte 5. Estático donde no hace falta JavaScript, SSR sobre Cloudflare Workers donde sí.
  • Pagos y datos: Stripe para checkout, Drizzle ORM y Valibot para esquema y validación en el borde.
  • Infraestructura: Cloudflare Workers, D1 y Durable Objects. wrangler para los tres.
  • Calidad: Vitest en pruebas de unidad, Playwright y axe-core en end-to-end y accesibilidad, OpenSpec para el ciclo de desarrollo.
  • Sistemas: Rust con axum, tokio y turso para la parte de logística y ACID.
  • Base: HTML semántico, CSS puro y TypeScript nativo.

Esto es mío

Y para cerrar, esto no es una maqueta: es mi escritorio. Arch Linux con la paleta Catppuccin, Nushell en Kitty, y las mismas herramientas con las que trabajo todos los días.

  • Sistema: Arch Linux sobre xfs, con GNOME
  • Shell: Nushell, estructurada y type-safe, con Zsh, Fish y fsh documentados aparte en GitHub
  • Terminal: Kitty, con el motor de renderizado propio
  • Editor: Helix, en modo modal y basado en selecciones
  • Configuración: dotfiles públicos, y la configuración de seguridad de Linux al aire
